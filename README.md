# miobiyori-figs

みお日和（X：[@miobiyori](https://x.com/miobiyori)）の X 投稿に添える図解の画像を置く、公開の置き場です。

## 使い方

- 画像は `figs/` に PNG で置きます。
- Buffer の画像 URL には、次の形の直リンクを使います。

  ```
  https://raw.githubusercontent.com/mioenglish0709-boop/miobiyori-figs/main/figs/<ファイル名>.png
  ```

- 置いた直後や差し替えた直後は、直リンクに反映されるまで数分かかることがあります。差し替えるときは、同じ名前で上書きせず、新しい名前で置きます。

## 決まり

- このリポジトリは**公開**です。誰でも見られます。
- 置いてよいのは、X 投稿用の図解の PNG だけです（`figs/` の中）。
- 個人を特定できる情報、口座番号、APIキーなどの秘密の値、公開前の検証の数字を、画像にもファイル名にも入れません。
- 置く人：Claude Cowork（ブラウザの「Add file → Upload files」で `figs/` に追加）。それ以外の変更は Claude Code が行います。
- サイト（みお日和）の記事で使う図は、Claude Code がサイトのリポジトリへ写して使います。サイトはこのリポジトリの画像を直接読み込みません。

## ファイル名

`YYYY-MM-DD_内容.png`（英数字・ハイフン・アンダースコアだけ。例：`2026-10-05_nisa-waku.png`）
